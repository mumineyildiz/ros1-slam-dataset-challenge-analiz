# Konya Dataset | ROS 1 SLAM Benchmark

Materials for evaluating indoor SLAM under aggressive motion, low light, reflections, repetitive geometry and moving obstacles. The ROS 1 recordings include 2D LiDAR, RGB-D, IMU, Leddar and ambient light data.

| Resource | Contents |
| --- | --- |
| [Original dataset and downloads](https://github.com/Konya-Dataset/Konya-Dateset#downloads) | ROS bags and available reference maps |
| [Sequence scores](dataset/Konya_Dataset_Challenge_Quantification.xlsx) | 41 sequences with ordinal challenge labels and recording metadata |
| [Annotation methodology](dataset/Konya_Dataset_Challenge_Quantification.docx) | Scoring rules and interpretation of CD, CLS and MCS |
| [Benchmark workbook](benchmark/Konya_Dataset_SLAM_Test_Analysis_Template.xlsx) | Run logs, error catalogue, dashboard and test protocol |
| [Evaluation protocol](benchmark/README.md) | ROS 1 replay, reference selection and reporting |
| [References](references/README.md) | Dataset, algorithms and trajectory evaluation |

The benchmark workbook is a template. Its experimental result sheet is currently empty.
